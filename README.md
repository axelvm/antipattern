# ANTIPATTERN

Site-jeu d’évasion bâti sur des anti-patterns web. Next.js (App Router) + TypeScript + Tailwind CSS.

## Démarrer

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build de production
- `npm run start` — serveur de production
- `npm run lint` — ESLint
